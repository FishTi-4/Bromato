# Bromato

一款使用 C++20 和 raylib 制作的俯视角无尽生存射击游戏。

## 游戏玩法

- 选择角色和地图后开始游戏。
- 玩家会使用持有的武器自动攻击附近的敌人。
- 击败敌人、拾取金币，在每波结束后进入商店购买道具和升级武器。
- 敌人会随游戏进行不断出现，玩家死亡后进入结算界面。

## 操作方式

- `W / A / S / D`：移动玩家
- 鼠标左键：操作菜单和按钮
- `F11`：切换无边框全屏
- 游戏界面右上角按钮：暂停游戏

## 编译与运行

开发环境：

- Windows 10/11
- Visual Studio 2022 或更新版本
- C++20
- raylib 6.0

编译步骤：

1. 使用 Visual Studio 打开 `Bromato.slnx`。
2. 选择 `x64` 和 `Debug` 或 `Release` 配置。
3. 生成并运行项目。

项目已经包含 raylib 依赖，正常情况下不需要额外配置。

## 主要目录

- `assets/`：图片、字体、音乐和音效资源
- `Scene*.h/.cpp`：各个游戏场景
- `Entity*`、`Player*`、`Enemy*`、`Bullet*`：游戏实体及对象池
- `*Manager*`：角色、地图、武器、道具、资源和音频管理
- `config/`：游戏设置
- `save/`：历史记录存档
- `main.cpp`：程序入口和窗口绘制逻辑
